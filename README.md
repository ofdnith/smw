# Lumi e o Arquipélago dos Faróis

Um platformer 2D original no espírito dos clássicos de 16 bits: corrida com impulso, pulo variável, mapa-múndi com saídas secretas, montaria e muitos segredos. Personagens, arte, música e fases são 100% inéditos e criados em código.

- **Plano completo:** [`docs/PLANO.md`](docs/PLANO.md)
- **Diário de desenvolvimento:** [`docs/diario.md`](docs/diario.md)
- **Jogar:** em breve no GitHub Pages (a partir do marco M0)

## Stack
TypeScript · Vite · Canvas 2D (320×180) · Web Audio (sintetizador próprio) · Vitest · Playwright · zero dependências de runtime.
